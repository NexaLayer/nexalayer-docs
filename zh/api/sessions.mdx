# Session API

Session API 是 NexaLayer 的核心。写操作建议携带 `Idempotency-Key`。

## 创建 Session

```bash
curl -X POST "https://api.nexalayer.net/v1/sessions" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $NEXALAYER_API_KEY" \
  -H "Idempotency-Key: create-session-001" \
  -d '{
    "session_type": "dynamic",
    "product_no": "dynamic_dyn3",
    "quantity": 0.25,
    "protocol": "socks5",
    "rotation_mode": "on_demand"
  }'
```

Dynamic Session 的 `quantity` 表示 GB，可以使用小数；Static Session 的 `quantity` 表示 IP 数量，必须是整数。价格按账号和产品实时计算，请以 `/products` 使用 IPProxy 汇率换算后的 USD 价格为准。

静态 Session 可包含：

```json
{
  "session_type": "static",
  "product_no": "static_us_englewood",
  "quantity": 1,
  "duration": 30,
  "protocol": "socks5",
  "country_code": "US",
  "city_code": "ENGLEWOOD",
  "project_id": "game"
}
```

## 查询 Session

```bash
curl "https://api.nexalayer.net/v1/sessions/$SID?include_credentials=true" \
  -H "X-API-Key: $NEXALAYER_API_KEY"
```

`include_credentials` 是查询参数，默认 `false`。`active` 状态下总会返回 `host`、`port` 和 `protocol`。只有 `include_credentials=true` 时才会返回 `proxy.username`、`proxy.password` 和 `proxy.full_url`。该参数不从 JSON body 读取。`POST /sessions` 不接受此参数，受理响应为 `status=creating`，不含代理凭据。

若读取价格后供应商价格已变化，创建会返回 HTTP 409 `PRICE_MISMATCH`，不会下单。请重新读取价格后再试。错误码说明见 [Error codes](/en/errors)。

## 轮换 Dynamic Session

```bash
curl -X POST "https://api.nexalayer.net/v1/sessions/$SID/rotate?include_credentials=true" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $NEXALAYER_API_KEY" \
  -H "Idempotency-Key: rotate-timeout-001" \
  -d '{ "reason": "timeout" }'
```

轮换同样只从查询参数读取 `include_credentials`，默认不返回用户名、密码和 `full_url`。续费接口不接受该参数；续费成功且 Session 为 active 时，响应会包含代理凭据。

支持原因：

```text
manual, scheduled, http_403, http_429, captcha, timeout, block
```

## 续费 Static Session

```bash
curl -X POST "https://api.nexalayer.net/v1/sessions/$SID/renew" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $NEXALAYER_API_KEY" \
  -H "Idempotency-Key: renew-static-001" \
  -d '{ "duration": 30 }'
```

## 终止 Session

```bash
curl -X DELETE "https://api.nexalayer.net/v1/sessions/$SID" \
  -H "X-API-Key: $NEXALAYER_API_KEY"
```

所有脚本都应该在清理步骤终止不再使用的 Session。
提前终止只释放底层资源；Session 管理暂时免费，Static 资源提前终止默认不自动退款。
