# Playwright

Recommended example:

```text
https://github.com/NexaLayer/nexalayer-examples/tree/main/playwright/basic-session
```

The example auto-selects a dynamic product, creates a Session, polls until active, maps `host / port / username / password` to Playwright proxy config, reports Telemetry, reads Health, and cleans up in `finally`. Username and password are returned only when the session read uses `include_credentials=true`.
