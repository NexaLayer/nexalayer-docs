# Session API

The Session API is the core NexaLayer surface. Send `Idempotency-Key` on write operations.

## Create a session

```bash
curl -X POST "https://api.nexalayer.net/v1/sessions" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $NEXALAYER_API_KEY" \
  -H "Idempotency-Key: create-session-001" \
  -d '{
    "session_type": "dynamic",
    "product_no": "dynamic_dyn3",
    "quantity": 0.25,
    "protocol": "socks5",
    "rotation_mode": "on_demand"
  }'
```

For dynamic sessions, `quantity` means GB and can be fractional. For static sessions, `quantity` means IP count and must be an integer. Always read the current price from `/public/products` or `/products` immediately before purchase.

If the supplier price changed since that read, create returns HTTP 409 [`PRICE_MISMATCH`](/en/errors). No order is placed. Read prices again and retry with the new quote and a new `Idempotency-Key`. `POST /sessions` does not accept `include_credentials`; the accepted response is `status=creating` and does not include proxy credentials.

A static session may include:

```json
{
  "session_type": "static",
  "product_no": "static_us_englewood",
  "quantity": 1,
  "duration": 30,
  "protocol": "socks5",
  "country_code": "US",
  "city_code": "ENGLEWOOD",
  "project_id": "game"
}
```

## Get a session

```bash
curl "https://api.nexalayer.net/v1/sessions/$SID?include_credentials=true" \
  -H "X-API-Key: $NEXALAYER_API_KEY"
```

`include_credentials` is a query parameter and defaults to `false`. When the session is `active`, `host`, `port`, and `protocol` are returned either way. `proxy.username`, `proxy.password`, and `proxy.full_url` are omitted unless `include_credentials=true`. The JSON body is not used for this flag. Request credentials only in the process that will connect, and do not log them.

## Rotate a dynamic session

```bash
curl -X POST "https://api.nexalayer.net/v1/sessions/$SID/rotate?include_credentials=true" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $NEXALAYER_API_KEY" \
  -H "Idempotency-Key: rotate-timeout-001" \
  -d '{ "reason": "timeout" }'
```

Rotate reads `include_credentials` from the query string, not the JSON body. The default is `false`, which omits `proxy.username`, `proxy.password`, and `proxy.full_url` from the rotated session.

Supported reasons:

```text
manual, scheduled, http_403, http_429, captcha, timeout, block
```

## Renew a static session

```bash
curl -X POST "https://api.nexalayer.net/v1/sessions/$SID/renew" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $NEXALAYER_API_KEY" \
  -H "Idempotency-Key: renew-static-001" \
  -d '{ "duration": 30 }'
```

Renew does not accept `include_credentials`. When the renewed session is active, the response includes proxy credentials.

## Terminate a session

```bash
curl -X DELETE "https://api.nexalayer.net/v1/sessions/$SID" \
  -H "X-API-Key: $NEXALAYER_API_KEY"
```

Every automation workflow should terminate sessions it no longer needs.
Early termination releases the underlying resource; session management is free for now, and static resources are not automatically refunded by default.
